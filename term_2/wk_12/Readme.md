Написать программу, решающую двумерное стационарное уравнение теплопроводности в прямоугольной области пространства с переменными по пространству коэффициентами.  
Для решения использовать метод установления, преобразовав уравнение к виду (∇,λ∇T) = ∂T/∂t , где t- переменная, имеющая смысл фиктивного времени.
Представить среду в виде сетки ячеек, в каждой из которых значение коэффициента теплопроводности постоянно.  
Для аппроксимации дифференциальных операторов конечными разностями использовать разностный шаблон `(y(i+1)-y(i)) / (x(i+1)-x(i))`  
Использовать граничные условия постоянства T на границах вдоль одного направления, и отсутствия потока `λ∇T=0` вдоль второго направления.
